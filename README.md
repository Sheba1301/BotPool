
# Headless Боты для Minecraft на основе MCC

Боты для Minecraft, работающие в headless-режиме (без графического клиента), на основе [Minecraft Console Client (MCC)](https://github.com/MCCTeam/Minecraft-Console-Client).

Боты разрабатывались под проект **ReallyWorld** для автоматизации ловли рыбы на встроенной работе (профессия «Рыбак»).

---

## 🚀 Запуск

1. Скачайте репозиторий из ветки **Releases** и откройте файл `Client.exe`.
2. Откройте в папке `ViaProxy` файл `ViaProxy-3.4.14.jar` — это прокси, необходимый для работы бота на версии **1.21.11**.
3. Нажмите кнопку **«Запустить»** в `ViaProxy-3.4.14.jar`.
4. В `Client.exe` расположено главное меню, из которого вы можете запускать ботов и управлять ими.

---

## ⚙️ Использование `Client.exe`

### Добавление аккаунтов

Ботов можно заносить через встроенное меню или вручную, открыв файл `config.ini`.

> ⚠️ Формат файла, мягко говоря, не идеален (знаю, можно было оформить красивее), но переделывать лень — работает, и пусть работает.

Данные вводятся в формате:

    НИК ПАРОЛЬ НомерГрифаСервера ИспользоватьАккаунт?(true/false)

Каждый аккаунт — с новой строки.

### Управление ботом

В будущем планируется централизованное управление ботами, а пока что — только командами в чат через:

    /msg НикБота Команда

#### Доступные команды

| Команда | Описание |
|---|---|
| `/msg НикБота tpa228` | Отправляет запрос на телепортацию указанному нику (главному при запуске бота). |
| `/msg НикБота tpa` | Сразу принимает ваш запрос на телепортацию. |

Таким образом, при желании эти команды можно использовать как импровизированный телепорт.

---

## 🎣 Как пользоваться

1. Запустите бота — он зайдёт на ваш гриф.
2. Дайте ему удочку.
3. Телепортируйте бота вручную на работу рыбака — там он начнёт фармить.

### Сбор прибыли

Собирать прибыль, увы, пока что неудобно — нужно вручную открывать консоль каждого бота и вводить команды:

1. Введите `/money` — увидите баланс бота.
2. Введите `/pay ВашНик Сумма` — переведёте деньги себе.

При повторных переводах можно просто нажимать стрелку вверх (как в обычной консоли), чтобы не писать команду заново.
